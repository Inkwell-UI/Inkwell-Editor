# Preview fonts

Fonts used only by the editor's Ruffle preview, as stand-ins for Skyrim's fonts when the user has not installed them (see `docs/preview-fonts.md`). They are never written into a mod or exported SWF.

| File | Family | Used for | Licence |
| --- | --- | --- | --- |
| `BarlowCondensed-Light.ttf`, `-Regular.ttf`, `-Bold.ttf` | Barlow Condensed (Jeremy Tribby) | Everywhere Light / Medium / Bold, and every other face without a lookalike | SIL OFL 1.1, `OFL-BarlowCondensed.txt` |
| `ShareTechMono-Regular.ttf` | Share Tech Mono (Carrois Type Design) | `$ConsoleFont` | SIL OFL 1.1, `OFL-ShareTechMono.txt` |

Source: the official Google Fonts repository, <https://github.com/google/fonts> (`ofl/barlowcondensed`, `ofl/sharetechmono`), unmodified. The OFL text sits next to the fonts; keep it when redistributing.
